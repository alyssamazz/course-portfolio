Learning objectives

By the end of this course you will be able to:

  • Define artificial intelligence in plain language, and distinguish the narrow AI in use today from the general AI that does not yet exist.
  • Explain how a model learns from training data and builds its answer one token at a time.
  • Choose the right category of AI tool for a given task, rather than defaulting to whichever one is most familiar.
  • Predict where AI output is most likely to be wrong, and scale your checking to what the decision is actually worth.
  • Classify information by sensitivity and decide what should never be pasted into a public AI tool.
  • Construct prompts that state the task, the context, the format and the constraints.
  • Refine a weak first response with specific corrections instead of starting the conversation over.

Glossary

Core concept How it works Tools and techniques Watch out for
Tools

Agent

A system given a goal rather than a single instruction, which takes multiple steps and calls other software on its own.

Core

AI (artificial intelligence)

Software that learns patterns from data and uses them to make predictions or decisions, rather than following rules a person wrote by hand.

Caution

Bias

Imbalances a model absorbs from its training data and reproduces in its output. Most consequential in decisions about people.

Mechanics

Context window

The fixed amount of text a model can consider at once. Anything outside it is invisible to the model.

Tools

Fine-tuning

Continuing to train an existing model on a narrower dataset. Good for style and format, poor for teaching facts.

Core

Generative AI

Models that produce new content such as text, images, audio or code, rather than only scoring or sorting data that already exists.

Caution

Hallucination

Confident output that is factually false. Most common around citations, figures, URLs and attributed quotes.

Core

Large language model (LLM)

A generative model trained on a very large body of text. Claude and ChatGPT are the familiar examples.

Core

Machine learning

Building behaviour from examples rather than from rules a person writes by hand. The technique behind almost all modern AI.

Core

Model

The trained system itself, the finished product of the learning process.

Core

Prompt

The instruction you give an AI assistant. Strong ones state the task, the context, the format and the constraints.

Tools

Retrieval augmented generation (RAG)

Searching your own documents and placing the relevant passages into the prompt, so answers come from material the model can see and cite.

Mechanics

Temperature

How adventurously a model samples its next token. Lower is more predictable, higher is more varied.

Mechanics

Token

The chunk of text a model actually processes, roughly three quarters of an average English word.

Core

Training data

The examples a model learned from. Its coverage and its blind spots shape everything the model does afterwards.
